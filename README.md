# Discord-бот: держатель голосового канала + лоу-фай

Бот входит в голосовой канал, держит его 24/7, переподключается сам, если его
выкинет, и умеет играть треки / live-радио (лоу-фай) без скачивания на диск.

## Команды

| Команда | Что делает |
|---|---|
| `/join` | Зайти в голосовой канал (твой, если ты в канале, иначе из `.env`) |
| `/leave` | Выйти из канала и сбросить очередь |
| `/play <запрос>` | Играть трек или радио: название, ссылка или `lofi hip hop radio` |
| `/skip` | Пропустить текущий трек |
| `/stop` | Остановить и очистить очередь |
| `/pause` / `/resume` | Пауза / продолжить |
| `/queue` | Показать очередь |

Live-стримы (радио) бот крутит по кругу, пока включено воспроизведение.

## Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate          # Windows (на Linux: source venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env         # вписать TOKEN и CHANNEL_ID
python bot.py
```

Нужен **ffmpeg** в PATH: https://ffmpeg.org/download.html

## Деплой на Wispbyte

1. Создай репозиторий на GitHub и запушь папку проекта
   (`bot.py`, `requirements.txt`, `.env.example`, `.gitignore`, `README.md`).
   Сам файл `.env` в git **не попадает** (добавлен в `.gitignore`).
2. На Wispbyte → Create/Deploy bot → выбери этот репозиторий.
3. Настройка запуска:
   - **Start command:** `python bot.py`
   - **Python-зависимости:** Wispbyte ставит автоматически из `requirements.txt`
     (это стандарт — если у тебя в панели поле под команду установки, используй
     `pip install -r requirements.txt`)
4. **Переменные окружения** (панель Wispbyte, раздел Environment/Variables):
   - `TOKEN` = токен бота
   - `CHANNEL_ID` = `811869324390170639`
   - `VOLUME` = `0.6` (по желанию)

   Если панель не умеет переменные окружения — положи заполненный `.env` в корень
   репозитория и сделай репозиторий **private** (токен не должен быть публичным).
5. Запусти. В логах должно появиться `Запущен как ...` и
   `Зашёл в голосовой канал ...`.
6. Slash-команды: команда `/play` появится сразу после первого запуска
   (синхронизация происходит автоматически). Если нет — перезайди на сервер.

### Если ffmpeg отсутствует на хосте

В логах будет ошибка запуска ffmpeg. Решение: в панели Wispbyte есть консоль/терминал —
проверь `ffmpeg -version`. Если нет, напиши в поддержку хостинга или используй
альтернативный образ с ffmpeg.

## Оптимизация под free-тариф

- Только slash-команды, бот не парсит текстовые сообщения.
- Минимальные интенты (`guilds` + `voice_states`) — меньше трафика и RAM.
- Голос: Opus через libopus (нативный C), ffmpeg выдаёт 48 kHz PCM — почти ноль
  нагрузки на CPU; вся работа по кодеку делается в C.
- Музыка стримится напрямую в голос (yt-dlp → ffmpeg → Opus): 0 диска, 0 RAM под треки.
- Никаких лишних периодических задач: бот просто держит соединение.

## Безопасность

- `.env` с токеном не попадает в git.
- Если токен всё же утечёт — сбрось его на
  https://discord.com/developers/applications → Bot → Reset Token.
