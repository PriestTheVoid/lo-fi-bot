# Discord-бот: держатель голосового канала 24/7

Бот заходит в заданный голосовой канал и просто держит его:
возвращается, если его кикнули, и возвращает себя, если его перетащили
в другой канал. Никакой музыки, ffmpeg и yt-dlp — только голосовое
соединение, поэтому бот весит мало и почти не тратит ресурсы.

**Фактическое потребление (замерено):** ~56 MB RAM, CPU ≈ 0%, диск ~80 MB.

## Что умеет

| Возможность | Описание |
|---|---|
| Автозаход | При запуске сам заходит в канал из `CHANNEL_ID` |
| Авто-возврат | Если кикнули из голоса — возвращается через 3 секунды |
| Возврат в свой канал | Если перетащили в другой — переезжает обратно (до 5 раз за 5 минут, чтобы не воевать с админами) |
| `/join` | Зайти в канал (и включить режим «держать») |
| `/leave` | Выйти из канала и не возвращаться до `/join` |
| `/status` | Канал, сколько держит без обрывов, число переподключений, пинг голоса, аптайм |

Команды — только slash-команды, бот не читает текстовые сообщения
(минимальные интенты: `guilds` + `voice_states`).

## Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate            # Windows (Linux/macOS: source venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env           # вписать TOKEN и CHANNEL_ID
python bot.py
```

Нужен только Python 3.10+. **ffmpeg не нужен.**

Ожидаемые логи при успешном запуске:

```
Запущен как ИмяБота#0000
Slash-команды синхронизированы
В канале: 🤝 | Лобби
```

## Деплой на JustRunMy.App (бесплатный тариф)

1. Зарегистрируйся на https://justrunmy.app (карта не нужна).
2. **New App** → способ деплоя **Git** → подключи репозиторий
   `PriestTheVoid/lo-fi-bot`, ветку `main`.
   - Если панель не видит приватный репозиторий — разреши доступ через
     GitHub-авторизацию в панели (либо сделай репозиторий публичным:
     секретов в нём нет, токен живёт только в переменных окружения).
   - Альтернатива без Git: **Zip-деплой** — загрузи архив с
     `bot.py`, `requirements.txt`.
3. **Runtime/Image:** выбери Python (3.11/3.12).
4. **Build/Install command:** `pip install -r requirements.txt`
5. **Start command:** `python bot.py`
6. **Environment variables** (обязательно):
   | Ключ | Значение |
   |---|---|
   | `TOKEN` | токен бота из Discord Developer Portal |
   | `CHANNEL_ID` | `811869324390170639` |

   Переменные из панели имеют приоритет над `.env` — файл `.env` для деплоя
   не обязателен, но бот его тоже умеет читать (если положишь внутрь образа).
7. **Start** → в логах появится `В канале: ...`. Порт/домен для бота не нужны.

Cборка идёт по `Dockerfile` из корня репозитория (в нём уже прописан
`python bot.py` как команда запуска, ffmpeg и прочее не нужны).

Лимитов бесплатного тарифа (0.15 vCPU, 256 MB RAM, 0.3 GB диска) держателю
канала хватает с большим запасом.

## Что важно знать

- **Только один запущенный экземпляр.** Если запустить бота одновременно
  на хостинге и локально, два экземпляра одним и тем же токеном будут
  выкидывать друг друга из канала (в логах — частые переподключения).
- Боту нужны права **Просмотр каналов**, **Подключение**, **Разговор**
  (в приглашении уже заложены).
- `CHANNEL_ID` — обычный голосовой канал (ID берётся правым кликом по каналу
  при включённом режиме разработчика в Discord).
- Если бота удалили из канала вручную через панель участников — он вернётся.
  Чтобы он остался вне канала, используй `/leave`.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Весь бот: подключение к голосу, авто-возврат, команды |
| `Dockerfile` | Образ для хостингов с Docker-сборкой (например, JustRunMy) |
| `.dockerignore` | Не тащит в образ `.env`, `venv`, `.git` |
| `.env` | Локальные настройки (`TOKEN`, `CHANNEL_ID`) — в git не попадает |
| `.env.example` | Шаблон настроек без секретов |
| `requirements.txt` | Единственная зависимость: `discord.py[voice]` |
